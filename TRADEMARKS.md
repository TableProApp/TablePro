# Trademark policy

The code in this repository is licensed under the [AGPLv3](LICENSE). That license covers the code. It does not cover the name **TablePro** or the TablePro icon and logo, which identify the builds this project publishes. Section 7(e) of the AGPL lets a project keep those out of the license, and this file says what you can do with them.

The aim is simple: anyone who downloads something called TablePro gets the app this project ships, not a build someone else changed.

## What you can do

- Build TablePro from this source for your own use, changed or not. The AGPL allows that, including a build with the license check removed.
- Redistribute an official release unchanged, for example through a package manager, under the name TablePro.
- Package the unchanged source for a Linux distribution or a package manager under the name TablePro, with only the changes packaging needs.
- Say that your work is based on TablePro, works with TablePro, or is a fork of TablePro, in plain words that do not suggest it is TablePro.
- Use the name and icon to write about TablePro, review it, teach it, or link to it.

## What needs a different name and icon

- A build with any other change, such as new or removed features, a removed license check, or other branding. Rename it and replace the icon before you share it.
- A product, company, domain, app store listing, or package name that people could take for TablePro or for something made by this project.
- Anything that suggests this project endorses, sponsors, or supports your work when it does not.
- Selling copies, or builds with the paid features unlocked, under the TablePro name.
