# Architecture Decision Records

Decisions that hold for every platform that builds the shared core: its crates, their contracts and how each app reaches them. A decision only one app makes goes in that app's folder, such as `linux/docs/decisions/`.

The format, the statuses and how a later ADR changes an earlier one follow [the Linux decisions' README](../../../linux/docs/decisions/README.md): an ADR under a review gate with no code yet, such as G0 for the sync and key ADRs, is `Proposed` and amended in place until the gate passes, and an `Accepted` one changes only its Status line. An ADR here that changes a Linux ADR updates only that ADR's Status line and its row in the Linux index.
