### Explicitly out of scope unless product goals change

Do not create BookiE work for Apple-only services and clients, license-gated
features, Sparkle or AppleScript, or an in-app AI client. BookiE's governed MCP
server is the chosen agent interface. Plugin-engine expansion, pairing deep
links and iCloud-synced icons are also excluded. Reconsider loadable SQLite
extensions only through an explicit security decision.

## Selection rule

The comparison is the complete candidate inventory. The backlog contains only
selected work with an owner, acceptance layer and issue link. The sprint stays
the sole authority for 0.2.0 scope and order. When an item is selected, move
its concise statement into the backlog and create or link its issue; remove it
from this candidate section only when it is scheduled, accepted out of scope,
or implemented with evidence.
