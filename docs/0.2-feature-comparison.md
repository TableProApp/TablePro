### Explicitly out of scope unless product goals change

Do not create BookiE work for Apple-only services and clients, license-gated
features, Sparkle or AppleScript, or an in-app AI client. BookiE's governed MCP
server is the chosen agent interface. Plugin-engine expansion, pairing deep
links and iCloud-synced icons are also excluded. Reconsider loadable SQLite
extensions only through an explicit security decision.

## Selection rule

Additional unselected candidates from the [October 18 audit](archive/code-and-ui-audit-2026-10-18.md#peer-fixes-and-ux-ideas) are dialect-specific type completion and responsive overflow for crowded toolbars. Custom pending-state accessibility and high-contrast review belong with DOC-3/#561; search and statement-band responsiveness need measurement before selecting a fix. The report contains source evidence, proposed order and acceptance, not a new delivery queue.

The comparison is the candidate inventory. The backlog contains selected
post-release work with an owner, acceptance layer and issue link. The
[0.2.0 scope](0.2.0-scope.md) and [completion page](bookie-0.2-sprint.md)
record that release's boundary and status. When an item is selected, move its
concise statement into the backlog and create or link its issue; remove it from
this candidate section only when it is scheduled, accepted out of scope, or
implemented with evidence.
