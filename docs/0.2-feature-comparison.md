# BookiE 0.2 feature comparison

Checked 2026-10-08 against DBeaver, TablePlus and the macOS TablePro BookiE comes
from, and dbx (reviewed in
[the app-layer audit](archive/app-layer-external-audit-2026-10-06.md)). BookiE
entries cite where the feature lives; entries for the other clients are general
knowledge and were not re-verified. Gaps are candidate rows, not commitments:
the maintainer decides which belong to 0.2.

| Area | BookiE | DBeaver | TablePlus / TablePro | dbx |
|---|---|---|---|---|
| Drivers | 8 compiled in: PostgreSQL, MySQL/MariaDB, SQLite, SQL Server, ClickHouse, MongoDB, Redis, DuckDB (optional). Oracle out of scope (PKG-7) | 80+ via JDBC | about 15, Oracle and Cassandra included | many, JDBC sidecars |
| SSH and TLS | built-in and system OpenSSH, multi-hop, host-key trust prompts, TLS modes, SQL Server Kerberos. Jump chains are not editable (UI-1b) | yes | yes | yes |
| Editor | completion, formatter, statement shading and navigation, multiple results with pinning and gutter marks, `:name` parameters, text EXPLAIN, find and replace, vim keys | yes, visual plan | yes, visual plan | yes |
| Grid | inline edit with pending changes, filters, column hide/order, find, value viewer, row inspector, long-value preview (PERF-10), selection totals | yes | yes | preview and fetch on demand |
| Schema editing | structure tab for columns, indexes and foreign keys; create table from CSV | full | yes | yes |
| Import / export | export CSV, JSON, Markdown, HTML, XML, SQL, Excel, full-table background export; import CSV only | many formats | CSV, JSON, SQL | yes |
| Safety | policy guard, approval, read-only connections, audit journal, masking | read-only connections, confirmations | safe mode | regex safety, write-unlock toggle |
| AI | MCP server with scoped tokens and `bookie-agentd`; no built-in chat by choice | AI assistant | AI assistant | AI assistant |
| History and favorites | query history, favorites, saved queries, Open Quickly | yes | yes | yes |
| Packaging | Linux only: deb, Arch package, Flatpak manifest (not on Flathub yet) | Windows, macOS, Linux | macOS (TablePlus also Windows, Linux) | cross-platform |

## Gaps (candidate rows)

| Gap | Users affected | Size | Notes |
|---|---|---|---|
| Snapshot and restore of a database | analysts experimenting on data | large | accepted for 0.2.x after 0.2.0 ([ADR 0015](decisions/0015-database-snapshots.md) / SNAP-1); build order SNAP-2 (PostgreSQL), SNAP-3 (SQL Server), SNAP-4 (SQLite and DuckDB file copies) |
| FK navigation, enum pickers, paste TSV, estimated counts | everyone editing data | medium | UI-19, deferred by B3 |
| JSON and SQL import | people moving data | medium | export exists; import is CSV only |
| Visual EXPLAIN | performance tuning | medium | text plan exists |
| ER diagram | schema readers | large | not planned for 0.2 in the audit |
| Data compare between tables or databases | migrations, QA | large | nothing exists |
| Server output and timing breakdown | DBAs | medium | UI-20 |

BookiE leads on exact type and value preservation (ADR 0007), the policy guard with
its audit trail, and MCP with per-token scopes and connection allowlists.
