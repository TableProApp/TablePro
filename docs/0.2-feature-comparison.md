# BookiE feature comparison and parity candidates

Reconciled 2026-10-11 against the Linux source, current planning docs and the
upstream comparison report. Upstream release details are retained as reported
references and were not independently re-audited here. BookiE statuses below
are a source and documentation review, not a new runtime or release gate.
Candidate gaps do not change the 0.2.0 sprint or commit BookiE to a later
release. The [active sprint](bookie-0.2-sprint.md) owns current scope; the
[backlog](backlog.md) owns selected future work.

| Area | BookiE today | DBeaver | TablePlus / TablePro | dbx |
|---|---|---|---|---|
| Drivers | 8 compiled in: PostgreSQL, MySQL/MariaDB, SQLite, SQL Server, ClickHouse, MongoDB, Redis, DuckDB (optional). Oracle is out of scope (PKG-7) | 80+ via JDBC | about 15, Oracle and Cassandra included | many, with JDBC sidecars |
| SSH and TLS | Built-in and system OpenSSH, multi-hop, host-key prompts, TLS modes and SQL Server Kerberos. Jump-chain editing remains incomplete (UI-1b) | yes | yes | yes |
| Editor | Completion, formatter, statement navigation, multiple results and pinning, named parameters, EXPLAIN tree for PostgreSQL and SQLite, find and replace, optional Vim keys | yes | yes | yes |
| Grid | Inline edit, filters, hidden/reordered columns, find, value viewer, row inspector, long-value preview, selection sum/average tooltip | yes | yes | preview and fetch on demand |
| Schema editing | Structure editor for columns, indexes, foreign keys and column comments; create table from CSV | full | yes | yes |
| Import and export | CSV import; CSV, JSON, Markdown, HTML, XML, SQL and Excel result exports. Full-table export is refused unless a verified snapshot path exists | many formats | CSV, JSON, SQL | yes |
| Safety | Policy guard, approval, read-only connections, audit journal, masking and scoped MCP server | read-only connections and confirmations | safe mode | SQL guard and write-unlock toggle |
| AI | Governed MCP server and `bookie-agentd`; no built-in chat by product choice | assistant | assistant | assistant |
| History and saved queries | Query history, favorites, saved queries and Open Quickly | yes | yes | yes |
| Packaging | Linux: Arch, Debian and Flatpak manifest; Flathub and desktop acceptance remain open | Windows, macOS, Linux | macOS (TablePlus also Windows and Linux) | cross-platform |

BookiE's distinguishing contracts remain exact type/value preservation (ADR
0007), guarded database access and audited, scoped MCP consumers. Do not infer
parity from a name alone: compare observable behavior and the owning engine,
consumer and test evidence.

### Explicitly out of scope unless product goals change

Do not create BookiE work for Apple-only services and clients, license-gated
features, Sparkle or AppleScript, or an in-app AI client. BookiE's governed MCP
server is the chosen agent interface. Plugin-engine expansion, pairing deep
links and iCloud-synced icons are also excluded. Reconsider loadable SQLite
extensions only through an explicit security decision.

## Selection rule

The comparison is the complete candidate inventory. The backlog contains only
selected work with an owner, acceptance layer and issue link. The sprint stays
the sole authority for 0.2.0 scope and order. When an item is selected, move
its concise statement into the backlog and create or link its issue; remove it
from this candidate section only when it is scheduled, accepted out of scope,
or implemented with evidence.
