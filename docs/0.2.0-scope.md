# 0.2.0 delivery scope

## Status

The maintainer confirmed on 2026-10-18 that **0.2.0 delivery work is complete; release publication is pending**. This page records that completed scope. The [sprint handoff](bookie-0.2-sprint.md) points to subsequent work, and the [backlog](backlog.md) owns its order.

The previous blocker table and exit criteria are retained in the [completion handoff](archive/bookie-0.2-completion-handoff-2026-10-18.md). This update records the maintainer's completion statement; it does not invent fresh test, installed-package or soak results. Existing issue-specific evidence and follow-ups remain with their owners.

## Delivery boundary

0.2.0 is the Linux development release for the Arch/Hyprland target, with hotfixes to follow from use:

- PostgreSQL, MySQL/MariaDB and SQLite are the principal database paths; DuckDB is optional. SQL Server, ClickHouse, MongoDB and Redis retain the maturity and restrictions in [known limitations](known-limitations.md).
- GUI and agent operations share the governed policy/audit path. Lost write acknowledgement does not authorize replay, and agent output remains subject to masking.
- Arch/Hyprland is the selected desktop target. Debian/Ubuntu GNOME desktop expansion and Flatpak stay in the post-0.2.0 backlog.

## Publication and subsequent work

An immutable tag, artifacts and the public release are separate from delivery completion. The app and agentd manifests identify the completed 0.2.0 source version. This metadata change does not create a tag or publish a package or release.

New upstream adoption, broader engine matrices and development-tooling changes are post-0.2.0 work. They do not reopen this milestone. Preserve exact source/environment evidence when selecting or closing each follow-up.
