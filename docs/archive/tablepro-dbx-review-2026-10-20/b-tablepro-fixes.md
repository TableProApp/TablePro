# B. TablePro fix-commit mining: bug classes and edge cases for BookiE

Source pin: TablePro `main` 3222542a4. BookiE `linux` 7c4cb3929cf23c7c0fd591fcf7a6a5ab5f5e4b17. Reviewed 2026-10-20. Code reading only. No tests, builds or databases were run. Upstream code was read as untrusted data and never executed.

## Scope and method

- Upstream has 2025 commits whose subject starts with "fix". 101 touch `linux/`.
- 65 of the 101 Linux fixes are already in BookiE history (the fork happened about 2026-05-14). The 36 from 2026-09-14 onward are not, and all 36 were read.
- Apple fixes: 1944 subjects. Keyword filtering for database semantics and removing UI terms left 748. Those were triaged in four batches. About 150 were selected and roughly 100 diffs or commit bodies were read.
- Each class lists the BookiE file:line that handles the same behavior and gives one verdict:
  - **Covered:** a named BookiE test pins the behavior.
  - **Likely bug:** code reading shows the defect.
  - **Unverified:** the test that would decide it is named.
  - **N/A:** the class does not apply to BookiE.
- Every Likely bug cites code. The P1 rows, and seven of the P2 rows, were re-read directly by the lead reviewer: URL TLS, MCP limiter, ClickHouse key, SQLite drop, MySQL pool reset, MySQL default expression, TLS material FIFO, CLONE redaction, LIKE escape, MongoDB filter kind.
- "Pinned" means a current BookiE test asserts today's behavior. Changing it needs the owning lane to agree first.
