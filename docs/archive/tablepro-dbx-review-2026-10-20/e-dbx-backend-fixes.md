# E: dbx backend fix mining mapped to BookiE

Source pin: dbx `d1e88ab4b5b196d8b920b56ee8bc1735dcdc6269` (main, 2026-10-19, untrusted, read only); BookiE `linux` `7c4cb3929`. Reviewed 2026-10-20.

## Method

- Scope: 2,166 dbx commits whose subject starts with "fix" under `crates/`, `src-tauri/`, `plugins/`. Filtered to engines BookiE ships plus engine-agnostic SQL, values, paging, transactions, cancel, SSH/TLS, URLs, import/export and MCP.
- About 110 representative commits were read with their test hunks to extract the exact edge-case input. Each class was then traced to BookiE code and tests.
- Probes: a scratch crate called BookiE `sql_lex::split_statements`, `transaction_control` and `classify` for part D. No database, Docker or GTK test was run. Every "Likely bug" rests on cited code, not on a run.
- Spot-checked by hand before publishing: URL import TLS (`crates/storage/src/connection_url.rs:62,111-112`, test at :303-312 and caller `apps/linux/app/src/ui/app/organization.rs:170` saves without review), ClickHouse `mutations_sync` (`crates/drivers/clickhouse/src/lib.rs:89`), MySQL prepare-derived columns (`crates/drivers/mysql/src/lib.rs:598-616`), policy split (`crates/policy/src/rules.rs:97-115`), Redis `key_row` (`crates/drivers/redis/src/lib.rs:359-391`), SQLite memory pool (`crates/drivers/sqlite/src/lib.rs:70-87`), Mongo URI db path (`crates/drivers/mongodb/src/lib.rs:101-111`).
- Already recorded elsewhere and not re-filed: #893 lexical settings, #894 Mongo metadata, #895 MCP wide ints, #896/#897, #550 notices, #1073 duplicate labels, PEER-2, PEER-3, PG-01..PG-46, dbx #12202/#12394/#12435/#12468.

Verdict counts across 105 classes: Covered 43 (including covered by design, refusal or type gating), Likely bug 21 (one is a capability gap), Unverified 17, Recorded 12, N/A 10, Partly covered 1, N/A or Recorded 1.
