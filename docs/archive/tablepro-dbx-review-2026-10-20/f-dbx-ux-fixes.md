# F. dbx frontend/UX fix mining against BookiE

## Source pin

- dbx: `d1e88ab4b5b196d8b920b56ee8bc1735dcdc6269` (2026-10-19). Read only. Untrusted.
- BookiE: `linux` `7c4cb3929`. Paths below are relative to `apps/linux/app/src` unless they start with `crates/`.
- Method: `git log --format='%h %s' -- apps packages | grep -iE '^[0-9a-f]+ fix'` gave 2,886 commits. Engine-specific scopes were dropped (2,193 left). 875 commits in grid, tabs, query, export, completion, connection, ssh, settings, ui, layout, shortcuts, dialog, app, i18n and desktop scopes were read by subject. 150 editor/sql/sidebar subjects were read. About 110 commits were opened for body, diffstat and test names.
- No app was built or run. No BookiE test was executed. Verdicts come from reading code.
- Already recorded elsewhere, so not repeated: stale commit callbacks (2026-10-15 review), loaded-row search on the GTK thread, statement band buffer copy, high contrast scheme, pending-edit cues (UI-39), narrow layout, PG type completion, live messages/result switching, last-row clipping (all 2026-10-18 audit), local filter persistence across restart (UI-38), active cell edits on close (#1029), dialect lexer profile (PEER-2, #893).

## Top 15

1. P1 Likely bug: Ctrl+Enter / Ctrl+Shift+Enter while a run is active starts a second run and cancels the first locally (`ui/editor/split_view.rs:71`, `mod.rs:992-996`). Gate the shortcut like the button.
2. P2 Likely bug: Copy rows as TSV is lossy for BookiE-to-BookiE paste. Formula-leading text gains `"'` and NULL becomes `\N` text (`csv.rs:95,247`, `paste.rs:62-81`).
3. P2 Likely bug: Workspace restore keeps only the first 32 tab records, so later editor tabs lose their only copy of the query (`services/workspace_state.rs:543`).
4. P2 Unverified: Global window shortcuts (Ctrl+W, F5, Ctrl+S) may act behind an open `adw::Dialog` (`ui/app/shortcuts.rs:131`).
5. P2 Lacking: Run selected text.
6. P2 Lacking: Paste extends into new draft rows.
7. P3 Likely bug: New editor tab can repeat an existing "Query N" title (`workspace_tabs.rs:567`).
8. P3 Likely bug: Explain falls back to the whole buffer when no statement is at the cursor (`ui/editor/mod.rs:748`).
9. P3 Likely gap: No CTE or derived-table completion (`completion.rs:345`).
10. P3 Unverified: Scroll position and multi-row selection after F5 (`grid_render.rs:74-114`).
11. P3 Unverified: SQL result column widths reset on rerun.
12. P3 Unverified: Database name saved with surrounding whitespace (`connect_dialog/mod.rs:863`).
13. P3 Unverified: Cursor on a comment line above a statement runs the previous statement.
14. P3 Unverified: Grid keyboard focus after tab switch and dialog close.
15. P3 Lacking: BLOB save/load file and opt-in continue-on-error scripts.
