<Update label="v0.67.1" description="August 22, 2026">
  ### Bug Fixes

  - **Editor crashes on stale text**: The editor no longer crashes when layout, syntax highlighting, accessibility, an input method, dictation or Look Up reads text that a newer edit had already removed ([#2338](https://github.com/TableProApp/TablePro/issues/2338), [#2339](https://github.com/TableProApp/TablePro/issues/2339), [#2340](https://github.com/TableProApp/TablePro/issues/2340))
  - A search highlight or diagnostic underline now disappears with the text it marks, instead of staying put or jumping elsewhere in the editor ([#2341](https://github.com/TableProApp/TablePro/issues/2341))
  - The toolbar no longer sits on "Executing…" after a query ends, so Stop is not the only way back, and the session context buttons no longer empty out for the length of every query ([#2342](https://github.com/TableProApp/TablePro/issues/2342))
  - A SQLite query that stops early, because the database is locked or the volume returns an error, now says so instead of showing an empty table ([#2355](https://github.com/TableProApp/TablePro/issues/2355))
  - Stop now ends a SQLite query that is waiting on a database another program has locked, instead of leaving it to wait out the query timeout ([#2363](https://github.com/TableProApp/TablePro/issues/2363))
  - The XLSX, MQL and SQL Import plugins linked to a documentation page that did not exist. They now point at Import & Export
</Update>

<Update label="v0.67.0" description="August 21, 2026">
  ### New Features

  - **Code folding**: Fold statements, table bodies, CTEs, subqueries, `BEGIN` blocks and multi-line comments from the editor gutter. A collapsed region becomes a chip you can hover to peek at, folds are remembered when a tab is reopened, and Fold All, Unfold All and Toggle Fold are in the Query menu. It also works in the DDL and trigger views, the SQL import preview, the AI review sheet, chat code blocks and the JSON cell viewer
  - **Run one statement at a time**: The statement your cursor is in gets a faint background, and a run button appears in the gutter beside every statement. Both can be turned off in **Settings > Editor** ([#2278](https://github.com/TableProApp/TablePro/issues/2278))
  - **Statement navigation**: `Ctrl+Cmd+Left` and `Ctrl+Cmd+Right` step between statements, `Ctrl+Cmd+Enter` runs the current one and moves to the next, and `Option+Shift+Up` and `Option+Shift+Down` extend the selection a statement at a time ([#2279](https://github.com/TableProApp/TablePro/issues/2279))
  - **Named result tabs**: Each result is named after the statement that produced it, using a leading comment when you wrote one. Picking a result moves the editor cursor to the statement behind it ([#2280](https://github.com/TableProApp/TablePro/issues/2280))
  - **Find in results**: `Cmd+F` on a table tab opens a find bar over the grid. The counter says what it searched, so "3 of 12 on this page" is never mistaken for an answer about the whole table, and Search All Rows turns the term into a server-side filter
  - **Charts**: Draw query results as native bar, line, area and scatter charts, with a real time axis for date and timestamp columns. The chart keeps its type and axes across a page turn, a sort and a re-run. This is a Starter feature
  - **Back and Forward**: Step back through the tables you followed a foreign key into, from the toolbar or the View menu on `Ctrl+Cmd+[` and `Ctrl+Cmd+]`. Back restores the filters, sort, page and selected row you left behind, and stands down while a tab holds unsaved edits ([#2316](https://github.com/TableProApp/TablePro/issues/2316))
  - **Background notifications**: TablePro tells you when a slow query, import, export, backup or row save finishes while you are in another app, and clicking the notification selects the tab that ran it. Configure it in **Settings > Notifications** ([#2265](https://github.com/TableProApp/TablePro/issues/2265))
  - **Redis Sentinel and Redis Cluster**: Pick a Connection Mode in the connection form. Sentinel follows a failover to the new primary; Cluster reads the shard map, routes each command to the shard that owns its key, and follows MOVED and ASK redirects ([#1021](https://github.com/TableProApp/TablePro/issues/1021))
  - **MongoDB filters on nested fields**: Filter on paths like `customer.country` or `items.sku`, with **any element** and **same element** matching for fields inside an array, and values compared as the type the field actually holds ([#2315](https://github.com/TableProApp/TablePro/issues/2315))
  - **DuckDB over data files**: Point a DuckDB connection at a Parquet, CSV, TSV, JSON or NDJSON file. It opens read-only and never writes back
  - **MCP overhaul**: The server grew from 19 tools to 46, gained prompt templates built from the live schema, argument completion from real table and column names, and change notifications. It speaks the 2026-07-28 protocol revision, with the two previous revisions still supported
  - **Korean**: Full Korean localization for macOS, iPhone and iPad, with a 한국어 option in General settings (#2219, #2264)
  - **Third-party plugins**: A plugin signed with an Apple Developer ID installs after you agree to trust that developer by name. Unsigned and ad-hoc signed bundles are still refused
  - **Execution log**: Every database operation TablePro authorizes is recorded locally, statements stored as digests rather than text, and hash chained so an edited or removed entry can be detected. Nothing leaves the Mac
  - **Managed Safe Mode**: An administrator can set a minimum Safe Mode level for every connection through a macOS configuration profile
  - Editor tabs can be dragged to reorder them, with **Move Tab Left** and **Move Tab Right** on each tab's menu
  - Swipe left on a saved connection in the welcome window to reveal Edit and Delete ([#2310](https://github.com/TableProApp/TablePro/issues/2310))
  - Double-click a table, or press `Return` on it, to keep its tab instead of reusing the preview tab ([#2235](https://github.com/TableProApp/TablePro/issues/2235))
  - Execute All Statements is on the Execute button's menu, alongside `Cmd+Shift+Enter` ([#2230](https://github.com/TableProApp/TablePro/issues/2230))
  - **View > Result View** switches the results pane between Data, Structure, JSON and Chart from the menu bar
  - **Help > Acknowledgements** lists the 38 open source libraries TablePro ships, with the exact version, license and full license text of each

  ### Removed

  - MCP remote access. The server binds to this Mac only. Its certificate named only localhost, so no other device could ever have verified it

  ### Security

  - A read-only MCP token can no longer run a statement that writes. A statement TablePro does not recognize is treated as a write, and the ones that reach the filesystem or run a program are refused
  - A token limited to some connections no longer sees the names, hosts, ports and usernames of the others
  - Safe Mode asks again for MCP, where every path used to pre-clear the confirmation
  - With authentication turned off, a local caller is read-only and cannot administer anything
  - Secrets belonging to separately distributed drivers are stored in the Keychain and stripped from exported connections. Existing values move to the Keychain on the next save
  - The activity log records which token made each call, stores statements as digests, is hash chained, and is no longer readable by other accounts on the Mac
  - Repeated bad tokens are rate limited, including requests that carry no credentials at all
  - A pairing link is checked before it is used and its destination shown before you approve it, and an MCP session identifier is no longer usable as a credential
