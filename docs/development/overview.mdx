## Translating the app

Translate through Xcode's export and import, one XLIFF file per language. Never edit
`Localizable.xcstrings` by hand: Xcode is the only tool that writes it, so a translation diff holds
your language and nothing else.

```bash
xcodebuild -exportLocalizations -project TablePro.xcodeproj -scheme TablePro \
    -localizationPath Localization -exportLanguage fr
xcodebuild -importLocalizations -project TablePro.xcodeproj -localizationPath Localization/fr.xcloc
scripts/localization.py status              # coverage, per language
```

Between the two commands, translate `Localization/fr.xcloc` in Xcode, or its
`Localized Contents/fr.xliff` in any XLIFF editor. The export builds the app first. Commit the
catalog and not the export: `Localization/` is gitignored. For the iPhone and iPad app, run the same
commands on `TableProMobile/TableProMobile.xcodeproj` with the `TableProMobile` scheme.

Plugin and package strings live in the app's catalog, marked "Managed Manually" so that Xcode keeps
them. Run `scripts/localization.py plugins --add` after adding a `String(localized:)` to a plugin or
a package.
